# GeoCache

GeoCache is a geo-distributed caching system designed to deliver data from the nearest available server based on geographic location. The project demonstrates how multi-region architectures can reduce latency, improve performance, and provide better scalability for globally distributed applications.

### Key Features

* 🌍 Multi-region server architecture
* ⚡ Low-latency data access
* 🚀 FastAPI-based backend
* 🔄 Regional data replication
* 📡 Location-based request routing
* 📈 Designed for scalable distributed systems

GeoCache is built as a learning project to explore distributed systems, geographic routing, caching strategies, and multi-region application architecture.
